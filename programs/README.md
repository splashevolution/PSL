# Legacy PVM32 compatibility corpus

The `.pvm` files in this directory are retained as regression inputs for the
repaired PVM32/Python/Lean baseline.

Their source syntax and historical terminology are **not** the active PSL
research language and should not be extended as the main research direction.

New semantic-continuity experiments should live behind neutral contracts,
device models, realizations, and evidence rather than adding new Sanskrit or
Pāṇinian source constructs.

Historical superseded examples live under `programs/historical/`.
